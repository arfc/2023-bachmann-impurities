\section{Methodology}
We selected two advanced reactors for this work: the X-energy Xe-100 and 
the \gls{USNC} \gls{MMR}. These two reactors provide comparison across 
some notable reactor design spaces, such as power output and fuel form. 
Additionally, there is enough information about each design publicly 
available to model each design with a reasonable degree of accuracy. 
we created models of each core and performed neutronics analysis using 
Serpent \cite{leppanen_serpent_2014}. 

We used the Sanagmon200 model from \cite{richter_isotopic_2022}, shown in 
Figure \ref{fig:xe100_core}, to serve as an Xe-100-like 
core model. The model itself can be found at \cite{richter_zoerichterphlox_2022}. 


TRISO particles are modeled as a blended mix of the TRISO 
materials, not the explicit layers. Using a homogenized TRISO particle 
decreases the $k_{eff}$ of the core by 4.45\%, but it does 
reduce the total CPU time required to run the simulation 
\cite{richter_isotopic_2022}. Additionally, the difference in flux between 
the homogenized TRISO particle model and the heterogeneous TRISO 
particle model is within error across the span of the reactor 
\cite{richter_isotopic_2022}. 

This model includes pebble compositions for each pass the pebbles go through. 
This is a stagnant composition for each pass number, but the variations in 
compositions within a single pass would likely not cause significant 
changes in the isotopic composition of the fuel. Any non-uranium parts of 
the fuel composition were left constant. 

Burnup steps are \textbf{6 month increments???}, for 
the end of each pass. Model does not include cone-like region at the bottom of the 
Xe-100. Average core temp of 800 K \cite{richter_isotopic_2022}.

The points of comparison for this work include:
\begin{itemize}
        \item Neutron flux at \gls{BOL}, mid-cycle, and \gls{EOL}
        \item k-eff as a function of burnup
        \item $\beta_{eff}$
        \item Temperature feedback coefficients
\end{itemize}

For the \gls{MMR} model, the temperature feedback coefficients was determined 
by varying the fuel, moderator, and coolant temperatures between 
850 K and 900 K.

Neither model includes any control rods or burnable poisons. Currently haven't 
found any info about burnable poisons.
