\section{Methodology}
We selected two advanced reactors for this work: the X-energy Xe-100 and 
the \gls{USNC} \gls{MMR}. These two reactors provide comparison across 
some notable reactor design spaces, such as power output and fuel form. 
Additionally, there is enough information about each design publicly 
available to model each design with a reasonable degree of accuracy. 
we created models of each core and performed neutronics analysis using 
Serpent \cite{leppanen_serpent_2014}. 

We used the Xe-100-like model from \cite{richter_isotopic_2022}, which can 
be found at \cite{richter_zoerichterphlox_2022}, shown in Figure 
\ref{fig:xe100_core}.

The points of comparison for this work include:
\begin{itemize}
        \item Neutron flux at \gls{BOL}, mid-cycle, and \gls{EOL}
        \item k-eff as a function of burnup
        \item $\beta_{eff}$
        \item Temperature feedback coefficients
\end{itemize}

For the \gls{MMR} model, the temperature feedback coefficients was determined 
by varying the fuel, moderator, and coolant temperatures between 
850 K and 900 K.

Neither model includes any control rods or burnable poisons. Currently haven't 
found any info about burnable poisons.
